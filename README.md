
# Update Lab

A small open-source desktop application for learning
Electron, React, NSIS installers and auto-updates
through GitHub Releases.

## Tech stack

- Electron
- React
- Vite
- electron-builder (planned)
- electron-updater (planned)

## Development

Install dependencies:

```bash
npm install
```

Start Vite:

```bash
npm run dev
```

In a second terminal, start Electron:

```bash
npx electron .
```
